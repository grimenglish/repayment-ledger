# 우리집 상환장부 — 개인용 Streamlit

Streamlit Cloud에 올려 휴대폰·PC 브라우저에서 사용하는 앱입니다. 데이터는 본인의 Google Sheets에 저장합니다. 실제 상환 내역은 비어 있습니다.

## 기능
- 전체 2억, 엄마·본인 각 1억의 잔액과 반원 게이지
- 날짜·은행·실제 송금자, 총 송금액, 엄마·본인 원금 배분, 이자, 메모
- 월 목표(엄마 400만 / 본인 100만 기본), 빠른 입력, 예상 완납월
- 월별 조회, 수정·삭제, 잔액 추이, 엑셀 요약·내역·월별 합계
- 선상환 비교, 원금 초과·배분 불일치·미래 날짜 차단
- 로그인 전에는 데이터 조회도 실행하지 않음

## 1. 코드 업로드
본인 GitHub에 비공개 저장소를 만들고 이 폴더 안의 파일을 올립니다. 실행 파일은 `app.py`입니다. `.streamlit/config.toml`도 포함하세요.
실제 Secrets, 서비스 계정 JSON은 GitHub에 올리지 마세요.

## 2. Google Sheets 저장 연결
1. 본인 Drive에서 빈 스프레드시트를 만듭니다. 공개 공유를 끕니다.
2. URL의 `/d/`와 `/edit` 사이 ID를 복사합니다.
3. https://console.cloud.google.com/ 에서 프로젝트 생성 후 Google Sheets API를 사용 설정합니다.
4. IAM 및 관리자 → 서비스 계정 → 계정 생성 → 키 → JSON 키를 생성합니다.
5. JSON의 `client_email` 주소에 위 스프레드시트를 편집자로 공유합니다.
6. `secrets.example.toml`의 `spreadsheet_id`와 `[gcp_service_account]` 값을 채웁니다.

`ledger_events_v1` 탭은 자동 생성됩니다. 다른 탭은 변경하지 않습니다. 수정·삭제도 이벤트로 남기며 Excel에는 현재 유효한 내역만 표시합니다. 이벤트 탭을 직접 수정하거나 정렬하지 마세요.
동일 앱의 여러 화면 사이 변경 충돌을 감지합니다. 여러 별도 앱 배포에서 같은 시트를 동시에 수정하는 방식은 지원하지 않습니다.

## 3. 나만 로그인하기
권장 방식은 본인 Google 계정만 허용하는 로그인입니다.
1. Google Cloud → Google Auth Platform에서 OAuth 동의 화면을 설정합니다. 테스트 상태라면 본인 계정을 테스트 사용자로 추가합니다.
2. OAuth 클라이언트 ID → 웹 애플리케이션을 생성합니다.
3. 승인된 리디렉션 URI에 `https://본인앱.streamlit.app/oauth2callback`을 등록합니다.
4. Secrets에서 `login_mode = "google"`, `allowed_email = "본인@gmail.com"`으로 지정합니다.
5. 예시 파일의 `[auth]`, `[auth.google]` 주석을 풀고 OAuth ID/Secret, 긴 임의의 `cookie_secret`을 넣습니다.
6. Google에서 검증한 본인 이메일만 장부를 열 수 있습니다.

간단한 비밀번호 로그인도 됩니다. `login_mode = "password"`로 두고 `python make_password.py`로 생성한 `[login]` 값을 사용하세요. 해시를 저장하며 로그인은 8시간 유지됩니다. 실패 지연은 브라우저 세션 단위입니다. 본인 계정 확인은 Google 로그인이 더 적합합니다.
Streamlit Cloud 공유 설정에서도 앱을 비공개로 두고 본인만 허용하세요. 해당 옵션의 제공 조건은 계정에서 확인하세요.

## 4. Streamlit Cloud 배포
1. https://share.streamlit.io/ 에서 본인 GitHub 계정으로 로그인합니다.
2. Create app → 위 저장소 → Main file path `app.py`를 지정합니다. 하위 폴더에 올렸다면 실제 경로를 사용합니다.
3. Python 3.11 이상을 선택합니다.
4. Advanced settings → Secrets에 값이 채워진 TOML 전체를 붙여넣습니다.
5. Deploy를 누릅니다. 앱 주소 확정 후 Google OAuth와 Secrets의 redirect_uri를 동일하게 맞춥니다.
6. 휴대폰·PC에서 같은 앱 주소로 사용합니다. 브라우저를 닫아도 Google Sheets에 내역이 남습니다.

이 파일은 코드 묶음입니다. 본인 계정 연결 및 배포는 위 설정이 한 번 필요합니다.

## 계산 기준
각 1억에서 원금 상환액만 차감합니다. 이자는 별도 기록합니다.
완납월은 이번 달 남은 목표를 이번 달에 갚고 다음 달부터 매월 목표액을 갚는 가정입니다. 월 목표가 0인데 잔액이 있으면 계산하지 않습니다.
선상환은 이번 달 즉시 추가 상환하고 이번 달 목표에도 포함하는 가정입니다. 계산만 하며 내역에 저장하지 않습니다. 실제 납부일·이자율·연체료는 자동 계산하지 않습니다.

## 파일
app.py: 화면·로그인 / core.py: 계산·엑셀 / storage.py: Google 저장 / requirements.txt: 의존성 / secrets.example.toml: 연결 예시 / make_password.py: 비밀번호 설정 / tests.py: 검증

개발 확인: `pip install -r requirements.txt` 후 `python -m unittest tests -v`.
필요한 경우만 `.streamlit/secrets.toml`을 만들고 `streamlit run app.py`로 로컬 확인할 수 있습니다. 실제 사용은 Cloud 기준입니다.

## 금액 입력 개선 (v1.5)
금액 입력 아래에 숫자에 쉼표를 넣은 금액과 한글 읽기를 표시합니다. 입력 후 Enter를 누르거나 다른 칸을 클릭하면 갱신됩니다. 저장 버튼을 누르기 전까지 장부에는 기록되지 않습니다.
엄마 원금·본인 원금·이자를 자동 합산해 저장할 송금액을 보여줍니다. 은행의 실제 이체 금액과 같은지 확인하고 저장하세요. 별도로 이체 금액을 입력해 합계와 비교하는 옵션도 제공합니다.
한글 금액과 화면 갱신·자동 합산·비교 금액 불일치 차단을 포함한 자체 테스트 25개 통과.

## 하나은행 대출 (v1.6)
별도 탭에 대출 원금 7,000만 원, 연 4.6%, 중도상환수수료율 0.59%(v2.3에서 수정)를 적용했습니다. 상환 원금은 가족 장부에 합산하지 않으며 기존 시트의 이벤트에 별도 종류로 저장합니다. 기존 가족 내역은 유지됩니다.
하나은행 상환 저장·수정·삭제·월 조회·별도 엑셀 다운로드, 원금 잔액 게이지, 예상 월 이자, 상환에 따른 월 이자 감소, 상환 미리 계산을 제공합니다.
예상 월 이자는 원금 잔액 × 4.6% ÷ 12를 원 단위 반올림한 비교값입니다. 일별 이자 청구·금리 변경·상환 방식은 반영하지 않습니다. 반올림 때문에 표시된 두 월 이자의 차이와 표시한 감소액에 1원 차이가 날 수 있습니다.
수수료 예상은 상환 원금 × 0.59%이며 잔여기간 비율·감면·면제는 미반영입니다. 실제 확인한 수수료를 별도로 입력할 수 있고 예상/실제를 구분해 저장·출력합니다. 실제 납부 이자는 수동 입력하며 이자와 수수료는 원금 잔액을 줄이지 않습니다.
자체 테스트 31개 통과. 하나은행 계산·원금 초과 차단·가족 장부 분리·저장/수정/삭제·완납 화면·미리 계산 비저장·엑셀 출력을 포함합니다. 실제 Google 연결은 배포 환경에서 확인해야 합니다.

## 하나은행 엄마·본인 분리 (v1.7)
엄마는 2,000만 원, 본인은 5,000만 원으로 원금·상환액·잔액·예상 월 이자를 따로 계산합니다. 엄마에게 받은 돈으로 갚은 원금은 엄마 항목에, 본인 몫을 갚은 원금은 본인 항목에 입력합니다. 실제 납부 이자도 각각 입력할 수 있습니다. 출금 계좌가 같아도 원금 배분에 따라 각자의 잔액만 감소합니다.
상환 미리 계산과 수수료 예상도 엄마·본인 원금 기준으로 각각 표시합니다. 실제 수수료 입력은 은행 출금 총액 기준으로 유지합니다. 엑셀에는 엄마·본인 요약 시트와 개인별 원금·납부 이자 열이 추가됩니다.
이전 버전의 배분 없는 하나은행 내역은 그대로 유지합니다. 내역 수정에서 이전 원금·납부 이자 합계를 유지하면서 엄마·본인 금액을 배분하면 새 방식으로 저장됩니다. 배분 전에는 개인별 잔액·이자를 확정 표시하거나 새 하나은행 내역을 추가하지 않습니다. 가족 장부는 계속 사용할 수 있습니다.
자체 테스트 35개 통과. 개인별 상환·초과 차단·월 이자·이전 내역 보존 및 배분 저장을 추가 검증했습니다.

## 간편 입력 (v1.8)
첫 번째 '전체 현황' 탭에서 가족·하나은행 대출을 합친 엄마와 본인의 남은 원금 및 하나은행 예상 월 이자를 확인합니다. 하나은행 기존 기록의 배분이 미확인인 경우 개인별 총액은 확정 표시하지 않습니다.
상환 탭에서는 '엄마만 / 본인만 / 함께'를 선택하면 필요한 원금 입력칸만 표시됩니다. 원금 입력에는 +10만 / +100만 / 초기화 버튼을 제공합니다. 이자·실제 수수료·메모는 추가 입력을 펼쳐 기록합니다. 가족 대출의 은행·송금자는 최근 기록을 기본값으로 사용하며 최초에는 본인 이름을 입력해야 합니다.
'지난번과 동일하게'는 해당 대출의 가장 최근 상환일 기록을 불러오며 날짜는 오늘로 설정합니다. 잔액을 초과하는 금액은 남은 원금까지 줄여 표시하고 안내합니다. 이자·수수료와 금액을 확인한 뒤 직접 저장해야 하며, 불러오기만으로 저장되지는 않습니다.
저장 전에는 사람별 상환액과 상환 후 잔액을 확인합니다. 하나은행은 예상 월 이자 감소액과 수수료도 표시합니다.
'방금 저장 취소'는 현재 브라우저 세션에서 가장 최근 성공한 상환 저장 1건을 취소합니다. 새 내역은 삭제 이벤트를 기록하고, 수정 저장은 이전 내용으로 복원합니다. 취소 대상 내역이 다른 화면에서 수정·삭제되었으면 바로 취소하지 않습니다. 다른 내역 변경과 원금 초과도 확인합니다. 취소는 원본 시트 행을 지우지 않고 이벤트로 남습니다.
자체 테스트 41개 통과. 사람 선택·빠른 금액 버튼·최근 기록 불러오기·잔액 제한·새 기록 취소·수정 취소·기존 배분 전 기록 복원·변경된 내역 취소 차단을 추가 검증했습니다.

## 통합 엑셀 백업과 연간 안내 (v1.9)
'전체 장부 엑셀 백업'에서 가족·하나은행 장부와 모든 원본 이벤트를 한 파일로 내려받습니다. 현재 유효한 상환 내역뿐 아니라 수정·삭제 이력 및 백업 파일 기준 정보를 포함합니다. PC와 다른 저장 위치에 복사하고 파일을 열어 내용을 확인하세요.
다운로드 후 '백업 파일 저장 완료'를 누르면 완료 날짜가 구글 시트에 저장됩니다. 앱이 파일 저장 여부를 자동으로 감지하거나 PC에 자동 백업하는 기능은 아닙니다. 파일을 받는 도중 내역이 변경되거나 날짜가 지나면 최신 파일을 다시 받아야 완료 표시를 할 수 있습니다.
완료 날짜에서 1년이 지나면 앱을 열 때 백업 안내를 표시합니다. 백업 완료 기록이 아직 없으면 최초 상환 저장 시점에서 1년 뒤 안내합니다. 파일 다운로드만으로 안내를 끄지 않습니다. 2월 29일의 다음 연간 안내일은 다음 해 2월 28일입니다.
상환 내역은 구글 시트에 저장되므로 앱 종료·재시작·코드 재업로드와 독립적으로 유지됩니다. 구글 시트를 삭제하거나 직접 잘못 수정하는 위험에 대비해 큰 상환 후에도 엑셀 사본을 보관하는 것이 좋습니다. 엑셀 파일 자동 복원 기능은 아직 포함하지 않으며 원본 이력을 보관해 복원에 사용할 수 있게 했습니다.
자체 테스트 45개 통과. 연간 안내일·윤년·통합 파일·원본 이력의 재계산·확인 날짜 영속 저장·현재 파일 기준 확인을 추가 검증했습니다. 실제 Google 계정 연결이나 사용자의 PC 파일 저장은 자체 테스트 범위 밖입니다.

## 더 보기 쉬운 상환 화면 (v2.0)

- 전체 현황에서 엄마와 본인의 남은 대출, 누적 상환액, 상환 진행률을 큰 카드로 표시합니다. 엄마는 초록색, 본인은 파란색으로 구분합니다.
- 대출을 고르고 ‘상환 기록하기’를 누르면 해당 입력 탭으로 이동합니다. 구버전 Streamlit에서는 선택한 탭을 맨 앞으로 배치합니다.
- 저장 직후 상환 금액과 원금 변경을 크게 표시합니다. 하나은행은 예상 월 이자 감소와 실제/예상 수수료도 표시합니다. 기존 내역 수정은 새 상환과 구분합니다.
- 상환 내역은 날짜별 카드로 표시하고 10개씩 나눕니다. 각 카드의 상세 보기에서 해당 기록을 수정·삭제할 수 있습니다. 전체 표와 엑셀 다운로드도 유지합니다.
- 기존 Google Sheets 저장 형식을 유지하며, 이전 하나은행 배분 미확정 기록은 확인 전까지 개인별 감소액을 확정해서 표시하지 않습니다.

자체 테스트 49개로 저장·수정 결과, 이자 감소, 탭 이동, 기록 선택, 상환 진행률과 기존 저장·백업 기능을 확인합니다. 실제 배포 화면과 Google 계정 연결은 배포 후 확인해야 합니다.

## 제목 옆 응원 명언 (v2.1)

접속 시 7개 명언 중 하나를 무작위로 표시합니다. 입력·저장 등 화면 재실행에서는 문구를 유지하고, ‘다른 명언 ↻’를 누르면 직전과 다른 문구를 표시합니다. 인물 이름과 원문 출처를 함께 제공하며 한국어는 직접 번역했습니다. 명언 변경은 금액 입력이나 저장 기록을 바꾸지 않습니다. 자체 테스트 51개로 기존 기능과 명언 유지·교체를 검증합니다.

## 한눈에 보이는 대시보드 (v2.2)

전체 잔액과 누적 상환액을 남색 요약 패널에 표시합니다. 엄마·본인 카드에는 가족 대출의 이번 달 남은 목표액을 강조하고, 목표 달성·목표 미설정·완납을 구분합니다. 하나은행에는 월 원금 목표를 임의로 적용하지 않습니다.

카드의 ‘가족 상환 기록’과 ‘하나은행 상환 기록’을 누르면 해당 대출과 대상이 선택된 입력 화면으로 이동합니다. 새 기록의 금액·비용·메모를 초기화하고 날짜는 오늘로 채웁니다. 가족 정기 상환액 자동 채우기는 꺼지고, 자동 저장은 하지 않습니다. 잔액·계획 상세는 펼쳐서 볼 수 있게 하여 입력 화면에서 금액 입력을 먼저 보여줍니다.

새 상환으로 대출별 10% 구간을 넘거나 완납하면 저장 결과에 짧은 달성 문구를 표시합니다. 기존 기록 수정·비용만 납부·이전 미배분 기록에서는 새 상환 달성 문구를 표시하지 않습니다. 자체 테스트 55개로 목표액, 대상별 버튼 이동, 자동 채우기 상태, 달성 문구와 기존 기능을 검증합니다.

## 여자친구 대출 · 하나은행 수수료 수정 (v2.3)

여자친구에게 빌린 본인 대출 2,000만원·연 3%를 별도 탭으로 관리합니다. 처음 예상 월 이자는 5만원입니다. 갚은 원금, 실제 납부 이자, 메모를 저장하며 개인별 잔액과 전체 잔액에도 포함합니다. 원금을 갚으면 남은 원금과 예상 월 이자 감소액을 표시합니다. 실제 납부한 이자는 따로 입력하며 월 이자 예상치를 자동으로 실제 납부 내역에 넣지 않습니다. 상환월 일할 이자는 상환일·합의 기준에 따라 별도로 확인하세요.

여자친구 대출은 기록 수정·삭제, 방금 저장 취소, 반복 입력, 전액 채우기, 계산만 하는 미리 보기, 개별 엑셀과 전체 백업을 지원합니다. 월 원금 목표나 상환수수료는 임의로 추가하지 않습니다. 본인 최초 대출 합계는 1억7천만원, 우리집 전체 최초 원금은 2억9천만원입니다.

하나은행의 새 예상 수수료율은 0.59%입니다. 1천만원 상환 시 단순 예상 수수료는 59,000원입니다. 기존 0.49% 예상 수수료와 실제 납부액은 조회·백업 과정에서 바꾸지 않습니다. 과거 예상 기록을 수정 저장할 때에는 안내 후 현재 0.59%로 계산합니다. 실제 납부액은 ‘실제 수수료’로 입력하세요. 새 예상 기록에는 적용률도 저장하고, 과거 기록의 적용률은 내역·엑셀에서 확인할 수 있습니다.

자체 테스트 63개 통과: 기존 내역·이전 수수료의 보존 및 취소, 새 수수료 검증, 여자친구 저장·수정·삭제·동시 변경 방지·재접속·완납, 이자 계산과 백업 원본 재계산을 검증했습니다. 실제 Google 계정 연결 및 배포 화면은 배포 후 확인해야 합니다. 새 여자친구 이벤트를 지원하도록 압축 안의 모든 파일을 함께 덮어쓰세요. 추가 입력으로 수정 전 남은 원금이 음수가 되는 저장은 거부합니다.
